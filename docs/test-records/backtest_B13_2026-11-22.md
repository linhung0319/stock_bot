# B-13：核心折衷版——平時固定 SGOV 20%，持續跌破 200 日線才加碼現金（T77 前的補測）

> 日期：2026-11-22
> 起因：T76 之後使用者問「為什麼崩盤規則會贏固定比例」。解釋是崩盤規則的優勢集中在兩次慢慢跌的長空頭，輸在一兩個月就結束的下跌（29 年 19 次啟動中 11 次只維持一到兩個月）。由此提出折衷版，使用者要求測。
> 腳本：`backtest/b13_hybrid.py`（`backtest/b10_account.py` 加了 `hyb_n`、`hyb_sgov` 兩個欄位；加完後重跑 B-11、B-12，結果和已 commit 的完全相同）
> 原始輸出：`backtest/results/B13_summary.md`、`B13_core_only.csv`、`B13_segments.csv`、`B13_account.csv`

---

## 1. 結論

1. **折衷版（N = 3）把崩盤規則在長空頭的優勢拿回大約一半（年化）到六成（最大回撤），近十年只少一點。** 整個帳戶（動能只有波動度、自選有慢規則、三偏移平均）：

   | 核心 | 2000–2026 年化 / Sharpe / 最大回撤 | 2013–2026 年化 / Sharpe / 最大回撤 | 下單日 / 年 |
   |---|---|---|---|
   | 現在的崩盤規則（動能 M1） | 13.5% / 0.91 / -40% | 20.6% / 1.33 / -29% | 8.6；8.2 |
   | SGOV 20% | 12.6% / 0.82 / -50% | 21.2% / 1.37 / -29% | 8.2；7.9 |
   | SGOV 30% | 12.3% / 0.83 / -47% | 20.3% / 1.39 / -28% | 8.2；8.0 |
   | **折衷 N=3（20% → 50%）** | **13.0% / 0.87 / -44%** | **20.9% / 1.38 / -30%** | 8.4；8.0 |

   和 SGOV 20% 比：2000–2026 多 0.4 pp、Sharpe 多 0.05、最大回撤少 6 pp；2013–2026 少 0.3 pp、Sharpe 多 0.01、最大回撤多 1 pp；每年多約 0.6 個「加碼／解除」下單日。
   和 SGOV 30% 比：2000–2026 三項都較好；2013–2026 年化多 0.6 pp、Sharpe 少 0.01、最大回撤多 2 pp。
2. **只看核心，差距更明顯**：1998–2026 最大回撤 -34%（SGOV 20% 是 -46%，崩盤規則 -30%），Sharpe 0.78（0.68，0.79）；2013–2026 年化 11.4%（11.9%，11.3%）。
3. **N 改成 2 或 1，長空頭的保護差不多，近十年少得更多**：整個帳戶 2000–2026 三者都在 12.7～13.0% / 0.87～0.88 / -43～-44%；2013–2026 是 20.9%（N=3）、20.5%（N=2）、20.2%（N=1），下單日也較多。所以「折衷版有幫助」這個結論不靠 N = 3；N = 3 只是近十年代價最小。
4. **沒拿回來的部分，來自平時那 20%**：多頭裡一直有 20% 在 SGOV（2003–07 只看核心 +71%，崩盤規則 +85%），加上要連續三個月才加碼、進場比崩盤規則慢。

---

## 2. 規則

| 項目 | 設定 |
|---|---|
| 平時 | SGOV 20%（分母是核心），界線 ±5 pp，每月換股日檢查（同 B-11） |
| 加碼 | 換股日 SPY 前一天收盤 < 200 日均線，**連續 3 次** → SGOV 目標改成 50%（= 現在崩盤規則的「核心一半現金」），當天調過去 |
| 解除 | 某次換股日回到 200 日均線之上 → 回到 20%，當天調回 |
| 加碼期間 | 進出核心的錢照 50% 分；界線 ±5 pp 圍繞 50% |
| 敏感度 | N = 2、N = 1（N = 1 等於把崩盤規則疊在 20% 上） |
| 其他 | 同 B-11、B-12：整個帳戶用 B-8 主要方案，動能 M2（只有波動度）與 M1（現況）、自選有／沒有慢規則、三種換股日偏移、兩個期間；SGOV 計息；5 bp |

|---|---|---|---|---|---|---|---|
| 1998–99 多頭 | +50% | +36% | +42% | +38% | +42% | +38% | +34% |
| 2000–03 空頭 | -39% | -20% | -31% | -26% | -23% | -20% | -19% |
| 2003–07 多頭 | +92% | +85% | +75% | +66% | +71% | +72% | +72% |
| 2007–09 空頭 | -38% | -21% | -31% | -26% | -22% | -21% | -21% |
| 2009–19 多頭 | +330% | +242% | +238% | +193% | +220% | +194% | +191% |
| 2020 V 型 | +17% | +16% | +14% | +12% | +12% | +8% | +13% |

### 3.2 N = 3 的加碼紀錄（只看核心，偏移 0）

29 年 8 次：

| 加碼 | 解除 | 加碼時 SPY 距一年高點 | 結果 |
|---|---|---|---|
| 2000-12 | 2002-04 | -13% | 有用：之後 SPY 最多再跌約四成 |
| 2002-07 | 2003-05 | -21% | 有用：期間 SPY 最多再跌兩成，解除時 -6% |
| 2008-03 | 2009-06 | -14% | 有用：期間 SPY -29%；但解除在 2009-06，錯過 2009-03 起的頭三個月反彈 |
| 2010-08 | 2010-10 | -7% | 白做：兩個月後買回 |
| 2011-11 | 2012-01 | -10% | 白做 |
| 2016-03 | 2016-04 | -6% | 白做 |
| 2020-05 | 2020-06 | -16% | 反效果：在 V 型反彈中賣，一個月內 SPY +5%，再買回 |
| 2022-07 | 2022-12 | -20% | 反效果：加碼在 6 月的低點之後，期間 SPY +9%；2022 全年 -17% 對 SGOV 20% 的 -15% |

崩盤規則同期間啟動 19 次；N = 3 濾掉了 11 次一兩個月的，剩下的 8 次裡有 3 次有用、5 次白做或反效果。

## 4. 比現況好、比較差、不一致的

和現在的完整設計（崩盤規則＋M1＋自選慢規則）比，用 M2＋折衷 N=3：

- **比較差**：2000–2026 年化少 0.5 pp、Sharpe 少 0.04、最大回撤多 4 pp。
- **比較好**：2013–2026 年化多 0.3 pp、Sharpe 多 0.05；因 200 日線下單每年 0.55～0.63 天（現況 1.25 天）。
- **不一致**：和 B-11、B-12 一樣，看期間裡有沒有長空頭。折衷版是把兩邊的差距都縮小，不是兩邊都贏。

---

## 5. 限制

1. **N = 3 是看過資料之後提的**（「19 次裡 11 次只維持一兩個月」），有樣本內的成分。N = 2、1 一起列出，長空頭的保護三者差不多，所以結論不靠 N；但 N = 3 在近十年代價最小這一點，可能有部分是擬合。
2. **50% 照搬現在崩盤規則的「一半」**，沒有試其他比例；20% 是 T76 的建議值，也沒有試別的基準（照不做格點搜尋的規矩）。
3. **長空頭仍然只有兩次**；8 次加碼裡有用的 3 次都在 2000–03、2008–09 這兩段。
4. 加碼期間錯過反彈初段（2009-03～06），這是任何「確認後才解除」的規則都有的代價。
5. 其他限制同 B-11、B-12（SGOV 2020 年前用國庫券、整股與出金沒模擬、自選是事後挑的贏家、動能 1997–2007 有倖存者偏差）。
