# B-14：錢移出／移回動能、自選時暫放在哪裡（T77 前的補測）

> 日期：2026-11-22
> 起因：使用者問「移出動能的錢要直接放到核心（照比例），還是撤到 SGOV」；自選改成以論點為主後更難測，但同樣有這個問題。
> 腳本：`backtest/b14_parking.py`（`backtest/b10_account.py` 加了 `mom_park`、`own_park`；加完後重跑 B-11～B-13，結果和已 commit 的相同）
> 原始輸出：`backtest/results/B14_summary.md`、`B14_account.csv`

---

## 1. 結論

1. **動能減碼的錢：照比例進核心就好，撤到 SGOV 沒有額外好處。** 撤到 SGOV 等於多放約 6～8 pp 的現金，效果和「核心直接放 SGOV 30%」一樣、甚至略差（動能只有波動度、核心 SGOV 20%，三偏移平均：2000–2026 12.1% / 0.83 / -48%，SGOV 30% 是 12.3% / 0.83 / -47%）。依波動度減碼的時點是「動能股波動變大」，不是「股市要跌」，所以這筆現金沒有擇時的價值。放 VOO 和照比例進核心幾乎一樣（差 0.1～0.4 pp）。
2. **自選減持的錢：撤到自選自己的 SGOV 在 2000–2026 三項都較好，2013–2026 少 0.5～0.6 pp。** 核心 SGOV 20% 時：2000–2026 12.7% / 0.87 / -46%（進核心 12.6% / 0.82 / -50%）；2013–2026 20.6% / 1.39 / -30%（21.2% / 1.37 / -29%）。和同樣現金量的 SGOV 30% 比，2000–2026 也較好（12.3% / 0.83 / -47%），所以這裡有一點擇時的價值：自選股跌 20% 被減半時，同產業、大盤常常也在跌，進核心的 80% 照樣跟著跌。效果幾乎全來自 2000–02（事件 -23% 對 -31%），只有 3 檔股票、一次事件。
3. **兩者都撤到 SGOV 最保守**：折衷核心時 2000–2026 12.4% / 0.93 / -36%，2013–2026 19.3% / 1.43 / -28%，近十年每年少約 1.6 pp。主要是現金變多（平均 23～25%），不是擇時。
4. **下單日數不變**（同一組動能／核心內差 ≤ 0.1 天 / 年，全部在 7.9～8.8 天）：暫放只是把同一天的單從「買 VOO＋SGOV」換成「買 SGOV」。

建議見 §5。

## 2. 設定

| 項目 | 設定 |
|---|---|
| 暫放方式 | 都進核心：移出的錢進核心照比例分、移回時從核心照比例拿（B-11～B-13 的做法）；→ 原桶的 SGOV：錢留在原桶放 SGOV，移回時先用這筆、不夠才從核心拿；→ 原桶的 VOO：同上，放 VOO |
| 動能哪些錢算「移出」 | 只有比例改變減下來的（波動度減碼、M1 的 200 日線減半）；換股、跨桶上限的錢照舊進出核心 |
| 自選哪些錢算「移出」 | 慢規則減半的錢（代理）；加回時先用暫放的錢；沒有減半中的股票時，剩下的暫放錢還給核心。單檔上限減下來的錢照舊進核心 |
| 框架 | B-8 主要方案、自選有慢規則；核心 SGOV 20%（±5 pp）與折衷 N=3；動能 M2 與 M1；三種換股日偏移；2000–2026、2013–2026 |

## 4. 限制

1. **自選用慢規則當代理。** 新設計把有論點股票的 -20% 改成強制審查，減持會變少、時點取決於審查結果；暫放的錢有多少、放多久，回測不出來。這裡只說明「減持的錢放 SGOV 等著」這個方向在 2000–02 那種情況有用。
2. **自選只有 3～4 檔、事後挑的贏家；自選暫放的好處幾乎全來自 2000–02 一次事件。**
3. 暫放的錢在「沒有減半中的股票」時才還給核心；實際設計要定暫放多久（見 §5），不同的規則結果會不同。
4. 自選的買進改動（先買一半、加碼、下跌加碼、候補）都沒模擬；它們會用到同一筆暫放的錢，見 §5。
5. 其他限制同 B-11～B-13。

## 5. 建議（給 T77 / T78）

把「移出的錢」分成兩種：

| 種類 | 例子 | 放哪裡 | 理由 |
|---|---|---|---|
| **暫時的**（預期會回到同一個桶） | 自選減持（強制審查後決定減半）、先買一半時保留的另一半、下跌加碼的預備金、賣掉後等候補名單進場 | **原桶的 SGOV** | 回測：自選減持放 SGOV 在 2000–02 少跌 8 pp，同樣現金量比核心放 SGOV 30% 好；而且這筆錢本來就要買回，放 SGOV 不必先買 VOO 再賣 VOO |
| **永久的**（離開這個桶） | 論點不成立出清、移出自選、單檔上限減碼、動能換股差額、動能依波動度減碼 | **核心，照比例** | 動能減碼放 SGOV 沒有擇時價值，只是多放現金；要多放現金應該直接調核心的比例，一個地方決定現金就好 |

T78 要補的設計：自選暫放的 SGOV 要有期限（例如審查結論出來、或 N 天內沒有用到就還給核心），月報要顯示「自選暫放中的現金」，免得它變成第二個沒人管的現金部位。
