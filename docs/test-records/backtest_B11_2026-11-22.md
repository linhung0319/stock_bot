# B-11：核心固定 VOO：SGOV 比例（T75）

> 日期：2026-11-22
> 對應：`docs/plan/allocation_plan_2026-11-22.md` T75
> 腳本：`backtest/b11_core.py`（帳戶模擬 `backtest/b10_account.py`，共用 `b10_common.py`），執行 `uv run python backtest/b11_core.py`
> 原始輸出：`backtest/results/B11_summary.md`、`B11_core_only.csv`、`B11_account.csv`

---

## 1. 結論

1. **固定比例是「少放一點在股市」，不是擇時。** 只看核心，1998–2026 年化 / 最大回撤：不留現金 9.2% / -55%，SGOV 10% 8.8% / -51%，20% 8.1% / -46%，30% 7.4% / -42%。SGOV 每多 10 個百分點，年化約少 0.4～0.7 pp，最大回撤約少 4～5 pp，Sharpe 略升（0.64 → 0.66 → 0.68 → 0.71）。
2. **在有兩次長空頭的 2000–2026，現在的崩盤規則比任何固定比例都好；在 2013–2026 則相反。** 這一點要先講清楚，因為改成固定比例是已經定的方向：
   - 只看核心，2000–2026：崩盤規則 8.7% / Sharpe 0.81 / 最大回撤 -30%；SGOV 20% 7.4% / 0.66 / -47%。
   - 只看核心，2013–2026：崩盤規則 11.3% / 0.98 / -23%；SGOV 20% 11.9% / 1.04 / -27%；不留現金 14.1% / 1.01 / -34%。
   - 整個帳戶，2000–2026：崩盤規則 13.9% / 0.93 / -38%；SGOV 20% 13.2% / 0.85 / -49%。
   - 整個帳戶，2013–2026：崩盤規則 20.9% / 1.37 / -26%；SGOV 20% 21.8% / 1.42 / -29%。
   所以從崩盤規則換到固定比例，**放棄的是 2000–02、2008 那種慢慢跌一兩年的空頭裡少跌的部分**（整個帳戶最大回撤 -38% → -49%），換到的是 2013 年以後的 V 型回檔不會被 200 日線來回切（只看核心，崩盤規則在 2013–2026 每年 1.8 天因它下單、年化比不留現金少 2.8 pp；整個帳戶少 2.4 pp）。
3. **因比例而下單的日數很少，界線 ±5 pp 夠了。** 整個帳戶裡，只因為核心比例超出界線而下單的日子：±5 pp 每年 0.04～0.26 天，±3 pp 0.08～0.38 天，±10 pp 0～0.08 天；總下單日數幾乎不變（8.5 → 8.6）。有入金時入金本身會照比例把核心拉回，±5 pp 是 0～0.23 天。
4. **調回的方向是「跌深買 VOO、漲多買 SGOV」。** SGOV 20%、±5 pp，29 年 9 次：2002-10、2008-12 賣 SGOV 買 VOO（接近兩次空頭的底部），其餘 7 次是漲多後賣 VOO 買 SGOV（約每 3 年一次）。
5. **每天檢查不比每月好**：報酬一樣，下單日稍多（整個帳戶 0.38 對 0.15 天 / 年，2000–2026）。
6. **分母改用總資產（SGOV = 總資產 10%）沒有好處**：報酬、回撤和「核心的 20%」差不多，但動能、自選漲跌會讓核心占比變動，比例單獨下單的日子變多（0.19～0.30 天 / 年）。

帶進 T76 的核心候選：**SGOV 10%、20%、30%，界線都用 ±5 pp，每月檢查**；加上現在的崩盤規則、核心不留現金當對照。

## 2. 方法

| 項目 | 設定 |
|---|---|
| 甲：只有核心 | 整個帳戶都是核心（沒有動能、自選），看比例本身 |
| 乙：整個帳戶 | B-8 主要方案（20 / 30 / 50、跨桶上限、搭便車、自選 5% 分級、波動度緩衝 0.10），**動能維持現況（波動度＋200 日線減半）**，只換核心的規則 |
| 核心規則 | 不留現金；現在的崩盤規則（換股日 SPY < 200 日均線 → 核心一半現金）；固定比例 |
| 固定比例 | SGOV 10 / 20 / 30%（分母是核心）；界線 ±3 / ±5 / ±10 pp；每月換股日檢查，超出才調回原比例；另一列每天檢查 |
| 進出核心 | 其他桶減下來的錢、入金剩下的錢進核心時照比例分到 VOO 和 SGOV；從核心拿錢時照比例拿 |
| 分母改用總資產 | SGOV 目標 = 總資產 10%，界線 ±2.5 pp（核心約占一半，等於核心的 20% 左右） |
| 入金情境 | 每月一次、月報日後第 10 個交易日、金額 = 當時總資產的 1%（同 B-6） |
| VOO | 用 SPY 代理（資料較長） |
| 現金 | SGOV（2020-06 上市後）；之前用 3 個月國庫券（FRED DTB3） |
| 成本 | 每單位成交金額 5 bp；SGOV 不計成本，但 SGOV 的買賣算一張單 |
| 期間 | 甲：1998–2026、2000–2026、2013–2026；乙：2000–2026（自選 MU / NVDA / MSFT）、2013–2026（加 META），同 B-5～B-8 |

**模擬器驗證**：`b10_account.py` 是 `account_backtest.simulate_account` 的複製加擴充。用舊設定（崩盤規則、現金報酬 0、SGOV 不算單）跑 B-8 的兩列，年化、Sharpe、最大回撤、下單日數和 `B8_account.csv` 到小數點後四位都相同（2000–2026 13.73% / 0.917 / -39.9% / 8.53 天；2013–2026 20.76% / 1.368 / -25.8% / 8.21 天）。

## 4. 比現況好、比較差、不一致的

和現在的崩盤規則比：

- **2000–2026 全部較差**：所有固定比例的 Sharpe（0.82～0.88 對 0.93）和最大回撤（-45～-53% 對 -38%）都較差，年化差 0.3～1.0 pp。
- **2013–2026 大多較好**：SGOV 10～20% 年化多 0.9～1.8 pp，Sharpe 1.38～1.42 對 1.37；最大回撤較差（-29～-32% 對 -26%）。SGOV 30% 年化差不多（20.8～21.2%）、Sharpe 1.44～1.45。
- **下單**：崩盤規則每年約 1.3～1.8 天因它下單（多半和動能換股同一天）；固定比例 ±5 pp 只有 0.04～0.26 天。兩者都沒有讓總下單日數明顯變多。
- **不一致**：結論完全看期間裡有沒有慢慢跌的長空頭。29 年只有兩次（2000–02、2008），而且 1997–2007 的動能資料有倖存者偏差（核心本身不受影響）。

## 5. 限制

1. **只有兩次長空頭**。崩盤規則在 2000–2026 的優勢幾乎全來自 2001–02 和 2008，這兩段結束後它就是一個在 V 型回檔裡來回切的規則（只看核心，2013–2026 每年 1.8 天、年化比不留現金少 2.8 pp）。固定比例不依賴擇時，所以它的數字比較不受「下次空頭長什麼樣子」影響。
2. **SGOV 2020 年才上市**，之前用 3 個月國庫券利率逐日計息，沒有扣 0.09% 費用；2009–2015、2020–2021 利率接近 0。
3. **整股沒有模擬**：回測用金額比例，界線外才調回。實際上整股配不到剛好的比例，±5 pp 的界線也吸收了整股的誤差，但小帳戶的實際下單次數可能比這裡多一點。
4. **出金沒有跑**：出金時從核心「照比例拿」還是「先拿 SGOV」是 T78 的設計題，這次沒有模擬。
5. **乙的動能維持現況（含 200 日線減半）**，200 日線減下來的錢進核心後照比例分，所以「固定比例」列並不是完全沒有 200 日線；動能拿掉 200 日線的組合在 T76。
6. 核心用 SPY 代理 VOO；手續費 5 bp、SGOV 不計成本。
