> 日期：2026-11-07
> 對應：`design_v2_momentum_2026-11-07.md` §2.1 第 5 點（搭便車）、§2.1.1（入金與出金）
> 腳本：`backtest/account_backtest.py` 的 `run_b6`，執行 `uv run python backtest/account_backtest.py`（跑完 B-5 接著跑 B-6）
> 原始輸出：`backtest/results/B6_summary.md`、`B6_account.csv`、`B6_orders_<年>.csv`（新主要方案每一次下單，附原因）、`B6_withdraw_orders_<年>.csv`（出金當天的單）

## 1. 結論

1. **搭便車沒有代價。** 只因比例漂移而下單的日子從每年 0.3～0.5 天降到 0～0.2 天，年化不變（13.9%／20.4～20.5%）。剩下的 0.2 天是單檔上限，照設計可以單獨通知。2013–2026 單一股票最高占比從 16% 升到 18%。
2. **入金照目標分配，比全進 VOO 每年多 0.6～0.9 pp，自選桶不會被稀釋**（平均 21～22% vs 20%）。但這段期間的自選股是事後贏家，多出來的報酬大部分來自「入金也買了贏家」，不能當成規則本身的價值。規則真正的作用是讓自選桶維持在預算附近。
3. **入金當天給單**：下單日從每年約 8.5 天變成約 20 天，多出來的都是使用者自己入金、本來就要登入券商的日子，所以不算額外負擔。報酬和併進月報一樣（14.2%／20.6%）。**採用當天給單**（§4）。
4. **出金順序改成「核心現金 → 動能高於目標的部分 → VOO → 動能按比例 → 最後才是自選」**（§4）。第一版「先賣高於目標最多的格子」在 2021-11 出金 25% 時賣了 NVDA 10.4%，等於出金時做一次已經拿掉的自選桶上限。
5. **但只改順序，NVDA 下個月還是會被賣。** VOO 賣掉一大塊後 NVDA 的占比被推高，2021-12-01 的月報就因單檔上限賣 NVDA 6.7%（出金 50% 時 14.8%）。所以出金清單**先做單檔上限的檢查**：出金後會超過 15% 的自選股在同一份清單減回 10%，減下來的錢抵出金。最後 2021-11 的出金清單是 賣 VOO 24.1%、NVDA 5.4%、動能 4 檔共 3.9%，之後的月報不再為此賣 NVDA，出金一次做完。
6. **大額出金不會把核心掏空。** 2021-11 出金 25%：核心 61% → 57%；出金 50%：61% → 49%，自選 24% → 34%。不需要另外訂「大額出金按比例出」的規則。
7. 2008-10-15 出金 25%（崩盤規則啟動中）：全部從現金（短債 ETF）支付，一張單，沒有賣到任何股票。
8. 入金出金都不影響單位淨值的年化、Sharpe 和最大回撤（差異都在 0.3 pp 以內）。

## 2. 方法

| 項目 | 設定 |
|---|---|
| 基準 | B-5 的帳戶模擬：自選 20%、動能 32%、核心 48%；自選訊號併入月報；單檔上限 15%→10%；跨桶上限 15%→10%；**無自選桶上限** |
| 搭便車 | 動能留任股的 ±50% 拉回，只在當天本來就有其他原因的單時才做 |
| 入金 | 每月一次，金額 = 當時總資產的 1%（一年約 12%），一律當天給單。「月中」= 月報日後第 10 個交易日；「剛好在月報日」= 入金和月報同一天，合成一份清單 |
| 入金分配 | 用入金後的總資產算每一格的當下目標（自選：標準比重，減半狀態下為一半，上限 10%；動能：總資產 × 80% × 40% × 當下比例 ÷ 5，受跨桶上限限制），依缺口由大到小補，只買不賣。缺口小於總資產 0.25% 不補。剩下的進核心（崩盤規則啟動時一半放現金） |
| 對照 | 入金全部進核心（VOO） |
| 出金 | 一次 25%（另測 10%、50%）。2000–2026 在 2008-10-15（崩盤規則啟動中）；2013–2026 在 2021-11-15（高點附近）。先做單檔上限檢查（出金後超過 15% 的自選股減回 10%，抵出金）；再依序 核心現金 → 動能高於目標的部分 → VOO → 動能按比例 → 自選按比例 |
| 績效 | 單位淨值：入金買單位、出金贖單位，入金出金不算報酬 |
| 下單日 | 入金出金當天一定算一個下單日；短債 ETF 的買賣也算一張單 |

## 4. 使用者的決定（2026-11-07）

1. **入金一律當天給單。** 入金出金是使用者主動登入 Firstrade 操作的，當天做完，不想之後再操作一次。所以拿掉「離月報不到 5 個交易日就併進月報」的規則。入金剛好在月報日時，和月報合成一份清單。
2. **出金順序：核心現金 → 動能高於目標的部分 → VOO → 動能按比例 → 最後才是自選。** 為了讓出金一次做完，出金清單先做單檔上限檢查（見 §1 第 5 點）。

## 5. 限制

- 自選股是事後贏家，「入金照目標分配 vs 全進 VOO」的報酬差被高估。
- 入金比例固定（每月 1%），沒有測不規則或很大的單筆入金。
- 出金只測了兩個日期（2021-11 另測 10%、50%）。
- 2015 年以前的動能部位有倖存者偏差。
